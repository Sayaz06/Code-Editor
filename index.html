📖 Panduan Guna

  

    

      ☁ Firestore: Fail kod disimpan dalam cloud — sync antara phone dan laptop. Fail besar (>800KB) auto simpan ke Firebase Storage. 📱 localStorage: Cache tempatan sahaja — hilang bila clear cache browser.
    

    

      
Flow Kerja

      
1.Edit kat phone → autosave ke Firebase bila keluar textarea

      
2.Buka laptop → log masuk → fail dah ada dalam panel 📁

      
3.Edit → autosave → deploy terus dari KodEdit

    

    

      
Simpan & Buka Fail

      
☁Butang ☁ — simpan fail semasa ke Firebase terus

      
📁Butang 📁 — panel fail: tab Firebase, Tempatan, Backup

      
⬆Butang ⬆ — upload fail dari telefon/laptop

      
⬇Butang ⬇ — download fail ke peranti

    

    

      
Ganti Kod

      
🔄Tab Ganti — cari dan ganti satu blok kod, tidak kisah indent/space

      
⚡Tab Ganti Pukal — tampal banyak blok Cari/Ganti sekaligus (format AI)

      
↵Tekan Pergi untuk scroll dan highlight kod yang dijumpai

    

    

      
Pilih Baris

      
1.Tekan butang ☰ Pilih → tap baris mula

      
2.Tap baris akhir → bar pilihan muncul

      
→Boleh Salin, Potong, atau terus ke Ganti

    

    

      
Deploy ke GitHub

      
🚀Butang 🚀 Deploy — buka panel deploy, pilih app, tekan Deploy

      
📂Butang 📂 Browse — browse fail dalam repo, buka terus ke editor

      
🔍Butang 🔍 — check status GitHub Pages build

      
→Selepas deploy, button diblock sehingga Pages siap build

    

    

      
Preview

      
👁Butang Preview — buka HTML dalam tab baru + auto simpan ke Firebase

      
→Preview guna domain GitHub Pages — Firebase dan JS berfungsi

    

    

      
Shortcut Desktop

      
→Ctrl+Z = Undo, Ctrl+Y = Redo, Ctrl+F = Buka Ganti, Ctrl+S = Download
